# F1 Championship Generator

[English version](README.md)

Это консольная программа для симуляции чемпионата Формулы-1. Она генерирует квалификации и гонки, погоду, ошибки пилотов, аварии и технические сходы. Можно посмотреть личный зачёт, Кубок конструкторов, статистику и архив гонок или создать своего пилота.

Доступные сезоны: **1999, 2007, 2010, 2012, 2021, 2023, 2024, 2025 и 2026**.

## Установка и запуск на Windows

Готовая версия для Windows x64 работает без установки Python. Компилятор, среда разработки и дополнительные библиотеки не нужны.

1. На странице репозитория откройте раздел **Releases** и выберите версию **v1.0**.
2. В разделе **Assets** скачайте `F1-Championship-Generator-v1.0-Windows-x64.zip`.
3. Распакуйте архив в папку, в которую можно сохранять файлы, например в отдельную папку в «Документах». Не запускайте программу прямо из ZIP-архива.
4. Откройте `F1-Championship-Generator.exe`.
5. Введите номер пункта меню и нажмите Enter.

Все девять сезонов уже включены в исполняемый файл. Отдельного установщика нет. Для удаления программы достаточно удалить распакованную папку, предварительно сохранив нужные чемпионаты.

Архив **Source code (zip)** содержит исходный код на Python. Для запуска готовой программы скачивайте именно ZIP для Windows x64, указанный выше. Если его ещё нет в релизе, используйте инструкцию запуска исходного кода ниже.

## Как пользоваться

В главном меню четыре пункта:

- **Generate Championship**: выбрать сезон и сгенерировать чемпионат.
- **Create Your Driver**: заменить одного гонщика команды своим пилотом и провести сезон.
- **Load Championship**: открыть сохранённый чемпионат и архив его гонок.
- **Exit**: закрыть программу.

При создании пилота можно скопировать характеристики другого гонщика или ввести значения от 0 до 100. После чемпионата доступны статистика своего пилота и сравнение с напарником. Меню самой программы на английском языке.

## Сохранения и обновление

После чемпионата введите название сохранения или нажмите Enter для стандартного названия. Каждый файл получает новое имя, поэтому предыдущие чемпионаты не перезаписываются.

Сохранения находятся в папке `saves` рядом с исполняемым файлом. При запуске исходного кода эта папка находится рядом с `championship.py`. Она создаётся автоматически после первого чемпионата. Старые сохранения без названия также работают.

Перед обновлением закройте программу и скопируйте папку `saves` в безопасное место. Распакуйте новый релиз в новую папку и перенесите свою папку `saves` к новому исполняемому файлу. Эти же JSON-сохранения можно использовать с версией из исходного кода.

## Запуск исходного кода

Установите Python 3.9 или новее, скачайте ZIP-архив репозитория и распакуйте его. Файлы `championship.py`, `season_loader.py` и папка `seasons` должны оставаться рядом.

Откройте терминал в распакованной папке проекта и выполните:

```text
python championship.py
```

На Windows также можно использовать `py championship.py`, если установлен Python Launcher. На Linux и macOS команда может называться `python3 championship.py`. Готовый `.exe` предназначен только для Windows. Для запуска исходного кода дополнительные Python-библиотеки не нужны.

Если команда Python не найдена, проверьте, что Python установлен и доступен в терминале. Если окно исполняемого файла неожиданно закрывается, запустите его из терминала, чтобы увидеть ошибку. Если сохранения не записываются, перенесите распакованную программу в папку с правом записи.

## Ограничения

Результаты случайны и не повторяют реальные гонки. Характеристики пилотов и трасс, скорость и надёжность машин являются игровыми оценками, а не официальными измерениями. Скорость машины не меняется в течение сезона.

Каждая команда использует двух пилотов на протяжении всего чемпионата. В шести добавленных исторических сезонах выбраны гонщики с наибольшим числом участий на соответствующем месте в команде. Замены по ходу сезона, спринты, бонус за быстрый круг, половинные очки и административные санкции не моделируются. McLaren может набирать командные очки в 2007 году. Михаэль Шумахер участвует во всём сезоне 1999 года. Прежние пресеты 2023, 2025 и 2026 годов сохранены; историческая балансировка этих трёх сезонов для этого релиза не проводилась.

Модель не может точно воспроизвести надёжность всех машин и необычные гонки. Гран-при Бельгии 2021 года симулируется как обычная гонка. Для сезона 2024 года используется средний баланс сил без развития машин по ходу чемпионата.

## Проверки и сборка

Эти команды выполняются из папки с исходным кодом. Пользователям готового исполняемого файла они не нужны.

Запуск проверок:

```text
python -m unittest tests -v
```

Проверка баланса шести добавленных сезонов через игровые функции:

```text
python balance.py --seasons 1000 --seed 42
```

Для сборки исполняемого файла на Windows x64 установите PyInstaller на компьютере разработчика и выполните из папки проекта:

```text
python -m pip install PyInstaller==6.22.3
python -m PyInstaller --noconfirm F1-Championship-Generator.spec
```

Исполняемый файл появится в `dist`. Все сезоны включены в сборку. Проверенная сборка создана с Python 3.14.5 и PyInstaller 6.22.3. Пользователям готовой программы Python не нужен.

Результаты балансировки, исторические источники и известные отличия описаны в [RELEASE_REPORT.md](RELEASE_REPORT.md) на английском языке. В `balance_results.json` находятся результаты итоговой выборки, в `balance_history.json` записаны балансировочные запуски, а в `historical_reference.json` сохранена использованная историческая статистика.
